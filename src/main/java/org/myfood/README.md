# CA1 -  Food Storage Algorithms Architecture














## Task Description

A fast-food restaurant provides five different types of food for parties: **Burger, Pizza, Fries, Sandwich, and Hotdog.**
These food items are stored in a rectangular storage unit with **two sides: one at the front and one on the opposite side.**
However, the chef can either **use the front side for both adding and removing food items** or **use the front** side for **adding food** items and the **opposite side for removing them**. 
The **storage can hold up to 8 trays at a time**, and the food items have different weights and names that must be tracked as they are placed into and removed from the storage. 
The Java application should store each food item’s information, including its **name, weight (grams), the best-before date (maximum of two weeks), and the time** it was placed into the storage.
Design and develop a Java application that models this scenario using an appropriate data structure. 

### The Design must support the following operations:

* Add a food item name, its weight and best-before date into an application.
* You can add only a limited number of food items, and the **maximum capacity** of the storage is **8**.
* Allow food items to be removed from the storage as mentioned in the above scenario and based on your chosen data structure.
* The application should **display** the name of food items that are present at **the top.**
* The application should **provide the termination of the application**.
* Analyse and report the **time complexity of each operation** of the data structure.

### You are required to:

* Identify the most suitable Data Structure to be used as a solution to store the details of cakes along with weights. Implement this data structure in your application (10%).
* Implement the above scenario using a Java that supports the specified operations, applying OOP principles (Classes), while making suitable use of the identified data structure. Analyse and report the time complexity of each operation (add, remove, display, peek, search). Justify why the chosen data structure is suitable for this scenario. (40%).
* Test the application to make sure it works correctly and demonstrate validations using different inputs. Error handling must be performed in case there is no data in the system. (10%).
* Present your work in the form of a poster presentation along with video recording. Show the operations of the data structure along with validation of input values using NetBeans. Provide a link to Github repository and the screenshot of Github commits along with their time of commit. (40%)
